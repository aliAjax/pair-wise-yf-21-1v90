# hxyfront-62009 地毯修复纹样档案 · 补块套裁排布台

源提示词编号：2

给手工地毯修复工作室使用的前端项目：破损登记、旧毯料选料与补块套裁排布一条线，并把排布结果与修复进度联动更新。

## 功能

- **破损登记**：按毯登记破损轮廓（x/y/w/h）与绒头方向（0°=倒向毯尾，顺时针计），毯面标记图同步展示；老档案缺方向记录先挂「待确认」，确认后才生成补块需求。
- **选料套裁**：补块需求尺寸 = 轮廓 + 每侧 2cm 拼缝余量；同产区选料，自动避开毯料上已有补块；绒头方向跟着原毯走——旋转角由「毯料绒头→原毯绒头」唯一确定（90° 步进，反了灯下泛白）。
- **失效重算**：轮廓或方向一改，该破损所有已排/在队补块立刻失效（保留失效记录），按新版尺寸与方向立即重算。
- **双人提交**：毯料带版本号（乐观锁）。暂存方案基于版本快照；两人同时提交同一毯料时，后到者提交被拒并看到具体冲突位置，冲突补块退回排队等料。支持跨产区用料特批标记。
- **排队等料**：容量不够的补块按 FIFO 排队；新毯料入库后自动排空队列。
- **进度联动**：每张毯的排布进度、工序阶段与台账动态随每次排布变动同步重算。

## 技术栈

React + Vite + TypeScript。领域逻辑（`src/domain/`）为纯 TS，不依赖 UI。

## 本地运行

```bash
npm install
npm run dev        # 开发端口 62009
npm run sanity     # 领域逻辑自检（排布/失效/冲突/等料）
npm run typecheck  # tsc --noEmit
```
